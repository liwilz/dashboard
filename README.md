# Experimental Dashboard using ratatui

[![CI](https://github.com//template/workflows/CI/badge.svg)](https://github.com//template/actions)

Using template for component architecture by ratatui

## Phase 0: Basic widgets

get some basic widgets working, not overlapping.

## Phase 1: Layouts

Include an abstraction for layouts

- assigning widgets to areas automatically
- resizing widgets automatically

## Phase 2: Interactivity

Ideas of WM or Terminal Multiplexer like features:

- moving widgets around
- resizing widgets
- closing widgets
- opening new widgets

## Phase 3: Persistence

Ideas of saving the layout and restoring it on next run:

- saving the layout to a file
- loading the layout from a file

## Phase 4: Mouse interaction

Ability to change focus with mouse, resize, move widgets with mouse
